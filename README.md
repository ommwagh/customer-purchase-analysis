# 🛍️ Customer Purchase Behavior Analysis

## 📊 Overview
This beginner-level Python project analyzes customer purchasing behavior from a mock retail dataset. It focuses on identifying revenue patterns, customer activity, and high-value customer segments using the `pandas` library and basic data visualization.

## 🔧 Tools & Libraries
- Python 3.x
- pandas
- matplotlib
- seaborn

## 📁 Files Included
- `customer_data.csv` – mock transactional dataset (Customer ID, Region, Order Amount, Order Date)
- `customer_analysis.ipynb` – main Python notebook performing analysis and visualization

## 📌 Key Insights
- Total revenue generated across 300+ orders
- Number of unique customers and average order value
- Identification of high-value customers (defined as spending over £200)
- Revenue distribution by region visualized using a bar chart

## 🧠 Skills Demonstrated
- Data cleaning and exploration using pandas
- Aggregation with `groupby` and conditional filtering
- Data visualization with seaborn/matplotlib
- Communicating insights using markdown and inline comments
